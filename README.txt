CHROMO BOZ — GitHub Pages için hazır statik site

ÖNİZLEME: index.html dosyasını tarayıcıda açın. Kurulum gerektirmez.

YAYINLAMA
1. ZIP dosyasını bilgisayarınızda açın.
2. ZIP'in kendisini değil, içindeki index.html, styles.css, script.js, assets klasörü ve .nojekyll dosyasını chromoboz-website deposunun ana dizinine yükleyin. assets klasörünün yapısını koruyun.
3. GitHub Settings > Pages > Build and deployment altında Deploy from a branch seçin; main ve / (root) seçip kaydedin.
4. Yayınlanan adresi aynı Pages ekranında görebilirsiniz.
Resmî rehber: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
